# A.R.G. Renovation

Website for Roman’s handyman, carpentry and renovation services in Halifax,
Dartmouth and the Eastern Shore, Nova Scotia.

The current approved website is **index.html**, a self-contained file with
embedded images. Open it locally in Chrome for review.

GitHub Pages is configured for **main / (root)** after its one-time activation
in repository Settings → Pages. See [DEPLOYMENT.md](DEPLOYMENT.md) for activation,
Namecheap DNS, HTTPS verification and automatic updates after approved merges.

Existing historical HTML files are preserved. Do not use them to overwrite the
current index.html. Keep working ZIPs, credentials and local backups out of Git.
